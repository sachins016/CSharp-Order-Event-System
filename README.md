# CSharp-Order-Event-System

## Description
This is an Order Notification System developed using C#.  
The project demonstrates the use of Delegates, Multicast Delegates, and Events in an event-driven architecture.

When an order is placed, multiple services like Email, SMS, and Logger are notified automatically.

## Features
- Order Processing
- Email Notification
- SMS Notification
- Logging Service
- Event Handling using Delegates

## Technologies Used
- C#
- .NET
- Visual Studio
